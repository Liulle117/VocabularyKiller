# Vocabulary Killer

一个**完全本地运行**的背单词小软件（Windows / Python + PySide6）。

## 功能
1. **录入单词**：只需键入英文单词，自动从离线词库 ECDICT 生成**中文释义**和**音标(IPA)**。
2. **单词本永久保留**：所有录入过的单词都存进单词本；「清空今日单词」只把当前学习列表清零，
   **不会删除任何单词**，之后可随时调用复习。
3. **复习模式**：逐个显示「中文释义 + 等量下划线（下划线数量 = 单词字母数）」，
   键入正确的英文即算过关；答错会显示正确答案，结束后可「只练错词」。
   答完一题后**按空格键**即可直接跳到下一个。
4. **学习统计**：折线图展示每天「新增单词 / 复习次数」趋势（可切换近 7/14/30 天），
   另有总数、今日新增、今日复习、**连续打卡天数**、复习正确率等概览卡片，用来鼓励坚持。

## 目录文件
| 文件 | 说明 |
| --- | --- |
| `app.py` | 主程序（图形界面），源码运行入口 |
| `dictionary.py` | ECDICT 离线词典查询（标准库 sqlite3） |
| `wordbook.py` | 单词本持久化（`wordbook.json`） |
| `stardict.db` | ECDICT 离线词库（约 810MB，340 万词条，含音标+中文） |
| `wordbook.json` | 你的单词本数据（首次运行后自动生成） |
| `build_exe.bat` | 一键打包成 exe（需已装 Python） |
| `run_from_source.bat` | 源码方式启动 |
| `requirements.txt` | 依赖 |
| `Vocabulary Killer.exe` | 打包后的可执行文件（双击即用，需与 `stardict.db` 同目录） |

## 运行方式

### 方式一：双击 exe（推荐，最简单）
直接双击项目文件夹里的 **`Vocabulary Killer.exe`** 即可运行。
> ⚠️ `stardict.db`（词库）必须和 exe 在**同一个文件夹**；你的单词数据 `wordbook.json`
> 也会自动生成在 exe 同目录。首次启动会解压运行库，稍等几秒属正常。

如果还没有 exe（或改了代码想重新打包），双击 **`build_exe.bat`** 一键生成，
完成后 exe 会自动放到本项目文件夹里（与 `stardict.db` 同目录）。

### 方式二：源码运行
```bash
python -m pip install -r requirements.txt   # 安装 PySide6
python app.py
```
或直接双击 `run_from_source.bat`。

## 使用说明
- **录入单词**：在文本框里每行输入一个单词（可一次粘贴多个）→ 点「① 查询释义」预览
  （音标/中文可在表格里手动修改）→ 点「② 添加到单词本」。也可直接「查询并添加」。
  词库查不到的词会标红，你可以手动补全释义后再添加。
- **单词本**：可切换查看「今日单词 / 全部单词 / 指定日期」；
  「清空今日单词」= 当天列表清零但保留词本；选中行可「删除 / 设为今日 / 移出今日」。
- **复习模式**：选范围（今日 / 全部 / 指定日期）与是否随机 → 「开始复习」→
  看中文、按下划线字母数键入英文、回车确认；答完一题后**按空格键**可直接跳到下一个。
  结束显示正确率与错词，可一键「只练错词」。
- **学习统计**：顶部卡片显示总数 / 今日新增 / 今日复习 / 连续打卡天数 / 复习正确率，
  下方折线图展示每天的「新增单词」与「复习次数」趋势，可切换近 7 / 14 / 30 天。
  数据在录入与复习时自动累计，切到本页即刷新。

## 词库来源（如需在新机器上重新获取）
本项目使用开源词典 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）。
下载其中的 SQLite 版 `ecdict-sqlite-28.zip`，解压得到 `stardict.db`，放到本目录即可。
国内网络可用镜像前缀下载，例如：
```
https://ghfast.top/https://github.com/skywind3000/ECDICT/releases/download/1.0.28/ecdict-sqlite-28.zip
```
